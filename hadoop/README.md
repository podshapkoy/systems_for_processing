# Hadoop: контейнер для HDFS и YARN

Контейнер подключается к уже запущенному Hadoop, выполняет операции в HDFS и запускает MapReduce WordCount через YARN. Используется Hadoop **3.3.6**.

## Подключение

В текущем `run.sh` адрес задан как `192.168.34.2`:

- HDFS: `hdfs://192.168.34.2:8020`
- YARN ResourceManager: `192.168.34.2:8032`

Если среда задания использует имя узла, замените адрес в `run.sh` на `master` (HDFS `hdfs://master:8020`, YARN `master:8032`). Адрес контейнера должен быть доступен из контейнера. Скрипт ждёт HDFS и файл `/shadow.txt`; этот файл должен быть подготовлен проверяющей системой.

## Запуск

Из каталога репозитория:

```bash
docker build -t hadoop-homework ./hadoop
docker run --rm hadoop-homework
```

## Что выполняется

1. Создаёт в HDFS каталог `/createme`.
2. Удаляет каталог `/delme`.
3. Загружает текстовый файл с произвольным содержимым в `/nonnull.txt`.
4. Запускает Hadoop MapReduce `wordcount` через YARN для `/shadow.txt`; результат сохраняет в `/wordcount_output`.
5. Находит в результате строку счётчика для слова `Innsmouth` (с учётом регистра) и записывает число в `/whataboutinsmouth.txt`. Если слово не найдено, записывается `0`.
