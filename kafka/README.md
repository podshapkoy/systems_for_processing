# PyFlink и Kafka: обработка потока температур

Контейнер подключается к Kafka-брокеру, читает JSON-сообщения из `input_topic` и публикует результаты пяти потоковых преобразований. Используется `apache-flink==1.17.2`.

## Подключение

В `run.sh` и `flink_job.py` задан bootstrap server:

```text
192.168.34.2:9092
```

Брокер Kafka должен быть доступен по этому адресу из контейнера, а топики `input_topic` и `topic_task_1` … `topic_task_5` должны быть доступны для чтения и записи.

## Формат входных сообщений

`input_topic` содержит JSON-объекты с целочисленными полями:

```json
{"device_id": 1, "temperature": 1, "execution_time": 1}
```

Входной формат десериализуется через `JsonRowDeserializationSchema`. В выходных топиках сообщения публикуются как строки JSON с помощью `SimpleStringSchema` — это требование проверяющей системы.

## Запуск

Из каталога репозитория:

```bash
docker build -t flink-kafka-homework ./kafka
docker run --rm flink-kafka-homework
```

Скрипт ждёт доступности Kafka на порту `9092`, затем запускает PyFlink job. Job начинает чтение с самого раннего доступного сообщения в `input_topic`.

## Потоковые задания

| Топик | Обработка |
| --- | --- |
| `topic_task_1` | Пересылает `device_id`, `temperature`, `execution_time` без изменений. |
| `topic_task_2` | Переводит температуру из °C в °F по формуле `°F = °C × 1.8 + 32`. |
| `topic_task_3` | Пропускает только исходные сообщения, где температура выше `50 °C`. |
| `topic_task_4` | Добавляет среднее значение температуры по всем обработанным сообщениям с начала потока. |
| `topic_task_5` | Добавляет среднюю температуру по последним пяти сообщениям того же `device_id` (включая текущее). |

В заданиях 1–3 выход содержит поля `device_id`, `temperature`, `execution_time`. В заданиях 4–5 дополнительно присутствует `average_temperature`.
